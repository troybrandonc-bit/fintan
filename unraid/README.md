# Fintan on Unraid

Template for Community Applications: `fintan.xml`. Needs the Nvidia-Driver plugin. Set an API key (any long random
string), pick Fintan-9B (24 GB card) or Fintan-4B (16 to 20 GB), and point Open WebUI or any OpenAI-compatible app at
`http://[server]:8900/v1` with that key. Everything Fintan learns stays in `/mnt/user/appdata/fintan`.
